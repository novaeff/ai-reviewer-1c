# ai-reviewer-1c

Автономный инструмент автоматического код-ревью для платформы **«1С:Предприятие 8»**, интегрированный в Git и работающий полностью локально на базе **Ollama** и **Qwen2.5-Coder (7B)**.

---

## Зачем это нужно

В разработке на 1С модули объектов и общие модули часто разрастаются до тысяч строк. Прямая отправка таких файлов в компактную локальную нейросеть (7B параметров) приводит к потере контекста, долгой генерации и ложным срабатываниям.

В этом проекте используется **двухэтапная гибридная проверка**:

1. **Инкрементальный разбор и статический анализ (Python):** при коммите из индекса (`git diff --cached`) извлекаются только затронутые процедуры и функции, а также методы текущего модуля, которые их вызывают. Парсер маскирует строки и комментарии, определяет контекст компиляции, глубину циклов и открытых транзакций.
2. **Точечная верификация через локальную LLM (Ollama):** для модели автоматически собирается структурированный промпт с кодом конкретной процедуры, номером строки и описанием сработавшего правила.

---

## Архитектура проекта

```text
├── git_hooks.py   # Точка входа для Git pre-commit хука и управление статусом коммита
├── parser.py      # Лексический разбор BSL: маскирование строк/комментариев, поиск методов и директив
├── analyzer.py    # Статический анализ: циклы, транзакции, переменные Запрос, граф вызовов внутри модуля
├── rules.py       # База правил проверки с привязкой к контексту выполнения
├── reviewer.py    # Сборка промпта, взаимодействие с REST API Ollama и разбор ответа модели
└── utils.py       # Вспомогательные функции работы с текстом и строками
```

## Требования

- **Python 3.12+**
- **Git**
- **Ollama** (установленный локально)
- Модель **Qwen2.5-Coder (7B)** (в квантизации `Q4` занимает ~4,5–5 ГБ ОЗУ / VRAM)

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/novaeff/ai-reviewer-1c.git
cd ai-reviewer-1c
```

### 2. Установка модели в Ollama

Убедитесь, что служба Ollama запущена, и скачайте модель:

```bash
ollama pull qwen2.5-coder:7b
```

### 3. Подключение Git `pre-commit` хука

Создайте или дополните файл `.git/hooks/pre-commit` в репозитории с выгрузкой конфигурации 1С:

```bash
#!/bin/sh
python /путь/к/ai-reviewer-1c/git_hooks.py
```

Для Linux/macOS выдайте права на выполнение:

```bash
chmod +x .git/hooks/pre-commit
```

---

Если нужно выполнить срочный коммит в обход проверки:

```bash
git commit --no-verify -m "wip: промежуточное сохранение"
```
